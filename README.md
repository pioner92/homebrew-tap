# Pioner92 Tap

## How do I install these formulae?

`brew install pioner92/tap/<formula>`

Or `brew tap pioner92/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "pioner92/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
